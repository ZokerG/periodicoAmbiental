# periodicoAmbiental

Web del periódico ecológico **Segunda Vida Digital** (Ingeniería de Software · Universidad Surcolombiana), con la herramienta «¿Mi PC tiene segunda vida?».

- Web: https://zokerg.github.io/periodicoAmbiental/
- Desarrollo: `npm install` · `npm run dev` · `npm test` · `npm run build`
- Se despliega solo a GitHub Pages con cada push a `main` (`.github/workflows/deploy.yml`).
